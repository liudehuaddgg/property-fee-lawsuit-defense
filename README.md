# property-fee-defense

> 业主被物业公司起诉追缴物业费时的应诉方法论 —— 一个给 AI Agent 用的 Skill。

> A reusable skill for defending property-management fee lawsuits in China.

## 这是什么

收到法院传票，业主的第一反应通常是"服务太差我不交"。这是最弱的抗辩——《民法典》第 944 条第 1 款专门堵这条路。

这个 Skill 把实战中真正能减少金额的四类缺口整理成一套可复用的流程：

| 层 | 攻击点 | 法律依据 |
|---|---|---|
| 1 | 合同**根本没对业主生效** | 民法典 939、278 |
| 2 | 原告**没完成起诉前置条件** | 民法典 944(1)(2) |
| 3 | 原告**自己算不出**它主张的金额 | 民诉法 67 |
| 4 | 违约金**没有依据或标准错误** | 民法典 585(2) |

核心心法：**不攻击服务，攻击举证。**

## 能解决什么

- 判断这个案子**能不能打、怎么打、能压到多少**
- 生成答辩状、质证意见、书证提出命令申请书、调查取证申请书
- 判断是否适用小额诉讼程序、如何提异议
- 核验原告的金额算术（**反推法**：2678 元的诉请到底是按几个月算的）
- 识别合同**倒签**（落款日与条款内日期的矛盾）
- 准备庭审发问清单与调解底线
- 避开会反噬的九类主张

## 不能解决什么

- **不能代替律师。** 这是方法论与文书骨架，不是个案法律意见。
- 不能保证结果。小额诉讼一审终审，"一分不付"的概率很低。
- 不处理物业公司之间的合同纠纷、业委会换届、物业费涨价行政投诉。
- 不提供具体案件的胜诉率预测。

```bash

  ~/.claude/skills/property-fee-defense
```

### 手动

下载仓库，把整个目录放到你的 Agent 的 skills 目录下即可。目录名建议保持 `property-fee-defense`，与 `SKILL.md` 的 `name` 字段一致。

重启 Agent 后，问一句"物业费被起诉了怎么答辩"，应当触发本 skill。或直接查看 skill 列表里是否出现 `property-fee-defense`。

## 怎么用

**方式一：直接对话**（推荐）

```
我收到法院传票，物业公司起诉我欠物业费 4000 元，帮我看看怎么答辩。
```

Agent 会先问四个决定策略的问题（产权登记、是否缴过费、起诉日、产权面积），再按四层漏斗推进。

**方式二：指定步骤**

```
用 property-fee-defense，帮我做合同倒签检测。
```

**方式三：只要文书**

```
用 property-fee-defense 的模板，帮我起草书证提出命令申请书。
```

## 使用前必须准备的四项事实

**这四项没确认，答辩状只是草稿。** 这是本 skill 最重要的一条纪律。

| # | 事实 | 为什么关键 |
|---|---|---|
| 1 | 房屋**登记在谁名下** | 决定能否打"主体不适格"。搞错了会反噬 |
| 2 | 该物业**进场以来缴过费吗** | 缴过任何一期 = 自认合同关系，效力抗辩直接失效 |
| 3 | 起诉状**落款日** | 决定"未到期费用"能否主张、时效怎么算 |
| 4 | **产权证建筑面积** | 与计费面积不一致 → 计费基数直接不成立 |

## 一个必须知道的法律陷阱

《最高人民法院关于审理物业服务纠纷案件具体应用法律若干问题的解释》在 **2020 年 12 月修正后（法释〔2020〕17 号，2021-01-01 施行）全文只剩 5 条**：

- 原 **第 1 条**（前期合同/业委会合同约束业主）——**已删除**
- 原 **第 6 条**（经书面催交，合理期限届满仍未交纳）——**已删除**

相关内容已由**《民法典》第 939 条、第 944 条**吸收。

网上大量 2021 年之前的文章、模板、短视频仍在引用这两条。**庭上一旦被对方指出条文已失效，整套论证的可信度会崩。**

本 skill 的法条引用已全部按现行有效版本校验，见 [`references/01-法条与效力校验.md`](references/01-法条与效力校验.md)。

## 设计原则

1. **诚实优先**：对明显不利、且对方一定能证明的事实主动承认，换取其他抗辩的可信度。
2. **不把"没看到"写成"对方绝对没有"**：写"原告未提交"，不写"原告根本没有"。
3. **不主张注定失败的抗辩**：时效（多数案件不成立）、消法、公共收益返还抵销、反诉。
4. **程序优先于实体**：实体抗辩可以"酌情"，程序申请法官必须回应。
5. **数字必须闭环**：面积 × 单价 × 月数，三个数互相对得上。
