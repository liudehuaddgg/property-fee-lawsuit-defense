# 庭审与调解

## 一、开庭前三十分钟

只做三件事：

1. **看速查卡**（一页纸），只看三条主线，不要翻卷宗；
2. **确认数字**：面积、单价、月数、诉请、差额。这五个数必须能脱口而出；
3. **写好第一句话**，第一句说顺了，后面就稳。

**不要在开庭前临时改主张。** 定稿后改主意，庭上一定串。

---

## 二、五项必备材料

进法庭带：

- [ ] 身份证原件
- [ ] 授权委托书原件 + 结婚证/户口本（近亲属代理）
- [ ] 答辩状（法院份数 + 自留 1 份）
- [ ] 质证意见（2 份）
- [ ] 书证提出命令申请书、调查取证申请书（各 2 份，**已递交的带收件回执**）
- [ ] 证据原件（产权证、缴费记录、房产证复印件、与物业的聊天记录）
- [ ] 速查卡 1 页

---

## 三、发问五组（全文）

**发问纪律**：

- 一次只问一个问题，问完**闭嘴等答案**；
- 不要问开放式问题（"你们服务怎么样"），只问封闭式（"有没有""几天一次""在哪"）；
- 对方答"没有"就记下来，**不追击**；
- 对方答"有"就要求出示，**不当场质疑真实性**；
- 拿到答案就转向下一组，不要把发问变成辩论。

### A 组｜主体与合同效力（6 问）

| # | 问题 | 想要的答案 |
|---|---|---|
| A1 | 请出示物业服务合同**原件**。 | 拿不出 → 复印件不能单独定案 |
| A2 | 合同乙方处为什么没有公司公章？签字人有授权委托书吗？ | 没有 → 490 条瑕疵 |
| A3 | 业主大会是哪一天召开的？决议原件在哪？ | 拿不出 → 939 条不满足 |
| A4 | 那次表决选聘的是哪一家公司？**全称**是什么？ | 与原告名称不一致 → 主体问题 |
| A5 | 表决是在合同签订日**之前**还是之后？ | "之后" → 补正不能 |
| A6 | 合同有没有向物业主管部门备案？备案回执在哪？ | 没有 → 程序瑕疵 |

**收口句**：
> "审判长，A1 到 A6，原告一项都没能提交。民法典 939 条只承认两种合同对业主有约束力，两种都不是。"

### B 组｜服务履行（5 问）

| # | 问题 | 想要的答案 |
|---|---|---|
| B1 | 合同约定的服务标准是几级？附件一在哪？ | 拿不出 → 标准无法确定 |
| B2 | 保洁每天几次？原始记录在哪？ | 拿不出 → 944(1) 前提未证 |
| B3 | 绿化养护一年几次？记录在哪？ | 同上 |
| B4 | 秩序维护岗位几个人？排班表在哪？ | 同上 |
| B5 | 电梯维保记录、消防检查记录在哪？ | 同上 |

**收口句**：
> "贵司收了乙级的钱（1.1 元/㎡ 对应乙级基准价），却拿不出一天的服务记录。收了钱，要证明干了活。"

### C 组｜金额（7 问）

| # | 问题 | 想要的答案 |
|---|---|---|
| C1 | 计费面积 [X] ㎡ 的依据是产权证还是测绘报告？ | 拿不出 → 基数无据 |
| C2 | 起诉状写 [X] × [X] × 24 个月，请当庭算一下等于多少？ | 若它算 → [金额]；若不算 → 我方算给法庭 |
| C3 | 那 [主张金额] 元是怎么算出来的？ | 要求解释 |
| C4 | [主张金额] ÷ [月费] 约等于 [X] 个月。到底是 24 还是 [X]？ | 逼它承认月数矛盾 |
| C5 | 起诉状写的截止日是"[年].[月].3.1"这种不成立的日期，12 月没有 3.1 日，截止日到底是哪天？ | 逼它明确 |
| C6 | 起诉状落款日是 [日期]，为什么算到 [更晚的日期]？中间这几个月的服务当时发生了吗？ | 未到期费用 |
| C7 | 合同写住宅 [A] ㎡、非住宅 [B] ㎡，合计 [A+B] ㎡，同页又写总面积 [C] ㎡。差的 [C-A-B] ㎡ 是什么？分户的计费面积从哪个数里分出来？ | 面积自洽问题 |

**收口句**：
> "审判长，原告自己的公式，只能算出 [正确金额] 元。它主张 [主张金额] 元。这 [差额] 元差额，它解释不了。"

### D 组｜催告（4 问）

| # | 问题 | 想要的答案 |
|---|---|---|
| D1 | 书面催缴函一共几份？分别是什么时候发的？ | 只有 1 张照片 → 与"多次"矛盾 |
| D2 | 送达凭证在哪？谁签收的？ | 没有 → 张贴 ≠ 送达 |
| D3 | 那张照片是哪天拍的？拍摄设备的原始数据能当庭核验吗？ | 不能 → 电子数据存疑（证据规定 93） |
| D4 | 从最后一次催告到起诉，中间隔了多少天？ | 不足合理期限 |

**收口句**：
> "民法典 944 条第 2 款要求'催告 + 合理期限'。一张贴在门上的照片，既不能证明送到了我手上，也不能证明给了合理期限。"

### E 组｜违约金（3 问）

| # | 问题 | 想要的答案 |
|---|---|---|
| E1 | 合同约定的是日万分之五，起诉状主张 30%，依据是什么？ | 无依据 |
| E2 | 30% 是怎么算出来的？对应多少天？ | 算不出 |
| E3 | 贵司的实际损失是多少？有证据吗？ | 无证据 → 585(2) 酌减 |

**收口句**：
> "合同写日万分之五，起诉状写 30%，两个数没有关系。这一项请求没有依据。"

## 四、法庭上绝对不要说的话

| 千万别说 | 为什么 |
|---|---|
| "我没享受到服务，所以不交钱" | 民法典 944(1) 直接堵死，且显得不讲理 |
| "物业服务太差，要求全部免掉" | 需要连续证据，你收不到；一说就等于承认服务关系存在 |
| "公共收益应该退给我抵物业费" | 282 条：归全体业主共有，单个业主无权请求，会被驳回 |
| "我不是业主 / 原告告错人了" | 产权证一出示即被反驳（**除非确实登记在他人名下**） |
| "部分费用已过三年时效" | 从起诉日回推三年，多数案件各期都在内。没算清就说，会当场出丑 |
| "物业怎么拿到我身份证号的" | 起诉立案本来就要身份信息，说了没好处 |
| "这合同是伪造的" | 伪造是刑事指控，需鉴定；应说"存在倒签迹象""形成时间存疑" |
| "我要求庭审直播/曝光他们" | 与实体无关，激化对立，法官反感 |

## 五、突发情况应对

### 情况 1：原告当庭拿出一堆选聘材料

**不要慌，四步：**

1. **先卡程序**："该证据超过举证期限，请求法庭依《民事诉讼法》第 68 条责令原告说明逾期理由；理由不成立的，请求不予采纳。"
2. **要原件**：当庭核对原件，核对不了的**不认可真实性**。
3. **要时间**："原告当庭提交新证据，请求休庭给予质证准备时间。"（不要仓促认可）
4. **查内容**（关键三问）：
   - 表决票有业主本人签名吗？和业主名册对得上吗？
   - 计票结果和票数吻合吗？
   - 表决的是**这家公司**吗？表决时间在签约**之前**吗？

**一句话反问**：
> "这些材料为什么举证期限内不交？合同 X 月 X 日签的，选聘表决是什么时候做的？表决的是哪一家公司？"

> 即便它补交了，如果表决时间晚于签约日，仍然不能补正合同效力——签约时它还没有授权。

### 情况 2：法官劝你"该交就交，别折腾"

**不要顶撞，也不要松口。应答：**

> "审判长，我愿意承担应当承担的部分。但原告到现在没有提交服务标准和任何服务记录，
> 收费面积也没有产权证依据，它自己算的金额和起诉状写的月数对不上。这些不是我折腾，
> 是原告的举证没完成。请法庭给它一个举证期限。"

**姿态要软，立场要硬。**

### 情况 3：法官问"你到底欠不欠费"

**标准应答**：
> "是否欠费、欠多少，取决于原告能否证明四件事：合同对业主有效、计费面积准确、
> 服务已按标准提供、金额计算正确。这四项原告都还没有证明。"

**不要说**"我不欠"（会被追问"那你承认服务了吗"），也**不要说**"我欠但我不交"（等于自认）。

### 情况 4：原告律师人身攻击（"业主就是赖账"）

**不回应情绪，只回应事实：**
> "我从 2023 年 3 月起从未收到过任何缴费通知，原告今天也拿不出送达凭证。
> 请原告回答：催缴函发到哪了？"

### 情况 5：法官问你为什么两年多没交

> "因为这家物业进场时没有经过业主大会选聘，我从未认可它的收费资格，
> 也从未收到过任何正式的缴费通知或账单。"
>
> （**注意**：如果确实一分未缴，这是有利事实，不必回避；如果缴过，改为
> "我此前按通知缴纳过，后来因为……停止缴纳"，但**不要编造**。）

## 六、调解

### 三档方案

| 档位 | 金额 | 条件 | 说明 |
|---|---|---|---|
| **理想** | ≤ 800 元 | 一次性了结 + 互不追究 | 需原告证据链明显断裂 |
| **可接受** | 1500–2000 元 | 本金核减 + 违约金全免 + 原告承担诉讼费 | **最可能达成** |
| **止损** | ≤ 2500 元 | 法院倾向按合同判本金 | 超过此线不如让法院判 |

### 谈判五原则

1. **不先出价**。让原告报，或让法官提。
2. **先讲理后讲钱**。先陈述三处硬伤（无选聘、无催告、算错账），再谈数字。
3. **出价必须附条件**，且条件写进协议：
   - 一次性付清；
   - 原告放弃其余请求；
   - **本案及此前所有期间互不追究**（防止它把砍掉的部分另案再诉）；
   - 诉讼费由原告承担（或各半）。
4. **分期要写违约后果**。不写等于没谈。
5. **不当场签字**。说"我需要回去核对一下金额"，争取一次复核机会。

### 调解协议必写的三句

```
一、原告放弃本案其余诉讼请求；
二、双方就案涉房屋 2023 年 3 月至本案了结之日期间的物业费争议一次性了结，
    原告不得再以任何理由就上述期间另行主张；
三、如被告未按期支付，原告可就未付部分申请强制执行，但不得加收违约金。
```

> 第三句很重要：不写，原告可能在执行阶段又加一笔违约金。

### 调解 vs 判决的判断

| 情形 | 建议 |
|---|---|
| 原告证据链完整（有选聘材料 + 服务台账 + 送达凭证） | **倾向调解**，判下来大概率全额 + 违约金 |
| 原告证据链断裂，但法院倾向"事实服务关系" | **调解**，用硬伤压价 |
| 计费面积明显错误 | 可**不调解**，等判决核减 |
| 已过举证期限原告才补材料 | 可**不调解**，先打程序 |

## 七、庭后

1. **当天写庭审记录**：法官问了什么、对方答了什么、哪些没答上来；
2. **三日内提交代理意见**（如有必要），把庭上口头说的书面化；
3. **核对笔录再签字**。书记员记录的与你说的不一致，**当场要求修改**，不要事后申诉；
4. **保存全部材料**，包括递交回执、邮寄单号。

---

## 八、时间节点纪律

- 举证期限、答辩期限的**最后一日为节假日**的，**顺延至节假日后第一个工作日**；
- 计算方式：从收到文书的**次日**起算，不是收到当日；
- 所有申请书**越早越好**，不要等到开庭当天提交；
- 邮寄递交用**EMS 法院专递**，保留单号与内件清单照片。
